# internet-analysis
 
 This project analyzes data on internet usage from Our World in Data (via the World Bank and International Telecommunications Union)
 It  answers: 
1. how long does it take for internet to reach the majority of people in different countries, regions, and income brackets?
2. how much does internet usage accelerate over the years?
3. how did the growth of the internet compare across the 2000s and 2010s?
